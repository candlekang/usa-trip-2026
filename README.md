# USA Trip 2026

GitHub Pages 旅遊行程網站。

## 使用方式

1. 將 `index.html` 與 `assets/` 整個上傳到 GitHub repository。
2. GitHub repository 進入 **Settings → Pages**。
3. 在 **Build and deployment** 選擇：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. 儲存後等候 GitHub Pages 發布。
5. 網址通常會是：
   `https://你的GitHub帳號.github.io/你的Repository名稱/`

> 請勿只上傳 index.html，`assets/` 也要一起上傳，否則插圖不會顯示。
